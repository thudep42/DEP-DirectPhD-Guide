# 开发与交接

## 结构约定

项目使用React、TypeScript和Vite，部署为静态文件。网址采用哈希导航，构建资源路径为`./`，适配GitHub Pages项目子路径。没有后台和登录功能。

年度记录的`admissions.year`、`meta.defaultYear`和网址`year`参数统一保存**博士入学年**。`shared/admission-period.mjs`集中换算为推免年（入学年减1）和四年制本科参考年级（入学年减4），页面年度选择器只改变显示文字，不改变关联与统计。当前对应2024级、2027年推免、2028年博士入学；2023仍为上一届去向统计年级。

| 层次 | 入口 | 职责 |
| --- | --- | --- |
| 字段定义 | `shared/workbook-schema.mjs` | 中文表名、列名、配置、枚举 |
| 数据类型 | `src/types.ts` | 页面使用的数据结构 |
| 统一校验 | `shared/validate.mjs` | 白名单、必填、日期、关联、状态与汇总一致性 |
| 业务计算 | `shared/statistics.mjs` | 招生与去向汇总，不混淆未知和0 |
| 导入 | `scripts/import-workbook.mjs` | Excel读取、类型转换、校验、备份和原子替换 |
| 读取 | `src/data/load.ts` | 快照读取、超时、失败恢复、加载前校验 |
| 页面 | `src/pages/` | 三个页面，各自管理筛选展示 |
| 组件 | `src/components/` | 指标卡、提示、链接、图标等共享展示 |
| 发布 | `.github/workflows/pages.yml` | 手动校验、测试、构建、部署 |

`ExcelJS`只用于读取外部工作簿，不进入网页运行时。网页只获取`public/data/site-data.json`。统计与数据校验共用同一套逻辑，避免网页和导入工具口径不同。

## 数据扩展

新增人数、资料、年级、博士年度或显示名称不需要修改网页源码。稳定编号用于关联，名称用于显示。

新增字段时按顺序修改：

1. 确认字段是否适合公开；私人数据不能放入公开快照。
2. 更新`workbook-schema.mjs`、`types.ts`和字段说明；同步腾讯文档表头或交付模板。
3. 更新导入类型转换、`validate.mjs`和需要用到的统计逻辑。
4. 修改页面或组件，补充有意义的业务测试。
5. 如改变兼容的数据结构，增加格式版本、旧快照迁移工具和迁移步骤，不能只把配置版本号加1。目前校验器仅接受版本1。
6. 导入真实导出文件，在本地预览后手动发布。

可能的下一步包括：多届覆盖人数独立表、导师年度方向归属、不同招生口径、更多资料筛选。当前年级覆盖信息只在配置中保存默认年级一份，增加多届比例功能应先扩展数据结构。

导师的“博导汇总列入”表示当前师资快照；“年度招生”的“该年度博导列入”保存当年度判断，因此更新当前身份不会改变历史名单人数。导师方向目前关联到当前导师资料；如需记录归属变更，应新增年度方向字段并迁移旧记录，不能直接修改后把历史分组当成未变。

## 新增页面

在`src/pages/`创建页面；将公共展示拆到`src/components/`。在`App.tsx`增加导航、路由解析和页面渲染。继续使用相对资源和哈希链接，检查手机底部导航、安全区域及刷新行为。

## 测试与预览

```powershell
pnpm check:data
pnpm test
pnpm build
pnpm preview --port 4173
```

测试初始样本保存在`tests/fixtures/initial-data.json`，与日常发布快照分开。以后导入新的真实数据不会让固定的“初始56人”测试误报失败；当前快照由`check:data`和构建单独校验。

测试覆盖：方向与总数、未知计划、部分填写、增加年度、改显示名称、历史身份、占位状态、比例条件、重复与危险数据、失败保留及备份。增加功能时测试其业务边界，不要只复述页面结构。

手机检查至少320px和390px，平板768px，桌面1280px；确认无横向溢出、点击目标可用、数据加载失败可恢复。正式发布后另查实际Pages子路径与微信访问。

## 依赖与部署维护

交付时可运行`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-source.ps1`，在项目的`outputs/`生成一层项目目录的源码ZIP。打包采用文件白名单，不包含依赖、构建目录、原始Excel或本地备份；也可用`-OutputDirectory`指定交付位置。打包前先完成数据校验、测试和构建。

依赖版本与pnpm版本锁定；Actions固定完整提交标识。更新依赖或动作前阅读其官方变更记录，修改锁定文件，执行校验、测试、构建和手机检查。普通更新仍须手动触发发布。

未来自动同步腾讯文档时，用新的适配器生成同一套数据结构并经过同一套校验。需要密钥的同步放在可信后台或Actions Secrets中，不能放进网页或公开JSON。新同步功能不会取消预览和数据公开范围检查。
