# 字段说明（格式版本1）

表名和列名固定，数据从第2行开始；可以调整列顺序。每行只写一条基础记录，不要在数据表末尾加合计行。日期填有效的`YYYY-MM-DD`，是／否使用下拉选项，人数和排序填非负整数。

编号使用英文字母开头，只含字母、数字、下划线或短横线。编号一旦被关联就保持稳定；改显示名称不改编号。官网链接和资料链接只接受HTTP或HTTPS。

## 使用说明与配置

左侧A至C列是配置，右侧E至G列是辅助说明和核对公式，不导入网站。

| 配置项 | 类型／填写要求 |
| --- | --- |
| 数据格式版本 | 固定为1，结构升级须迁移工具同步支持 |
| 网站名称 | 非空文字 |
| 默认博士入学年度 | 2000至2200整数；初始2028，对应2027年推免、2024级参考。须有对应招生记录 |
| 默认本科入学年级 | 去向统计年级；初始仍为上一届2023级，不是当前大三2024级。须有对应去向记录 |
| 师资核对日期 | 有效日期 |
| 去向统计状态 | 初始占位／填报中／已核实，与默认年级行状态汇总一致 |
| 年级总人数 | 未知留空，已知填非负整数；只对应默认年级 |
| 已填报人数 | 未知留空，不能大于年级总人数 |
| 腾讯文档链接 | 可留空；填写想在网站展示的共享链接 |

导入工具自动生成“快照时间”，不在表格中手填。右侧同时展示博士入学年和推免年，推免年由入学年减1计算，不重复手填。

## 年度招生

| 列名 | 要求 |
| --- | --- |
| 博士入学年度 | 必填，2000至2200整数；2027年推免填2028，不填2027 |
| 导师编号 | 必填，关联导师资料；同年度同导师不能重复 |
| 该年度博导列入 | 是／否，保存当年度身份判断 |
| 假设人数 | 必填，非负整数。初始每位博导1；该年度未列入时必须0 |
| 确认计划 | 未知留空，已知填非负整数。0表示确认没有名额 |
| 实际人数 | 未知留空，已知填非负整数 |
| 适用口径 | 必填，说明估算、面向对象、直博或其他博士口径等 |

如果部分导师未填写确认计划或实际人数，网站显示“待补充”和填写进度，不能把已填部分的和当成完整计划。

## 去向汇总

| 列名 | 要求 |
| --- | --- |
| 记录编号 | 必填，唯一稳定编号 |
| 本科入学年级 | 必填，2000至2200整数；2023级填2023 |
| 路径 | 直博／硕士／就业／其他／待定 |
| 与清华的关系 | 工物系／清华其他单位／校外 |
| 机构类型 | 高校／科研院所／企业／其他 |
| 接收单位 | 可留空，如高校、研究院或企业名称 |
| 接收院系 | 可留空 |
| 本系方向编号 | 本系直博人数大于0时必填；其他本系去向可选；外系及校外留空 |
| 研究方向 | 可留空，可记录外系／校外方向文字 |
| 人数 | 必填，非负整数；初始占位只能为0 |
| 结果状态 | 意向／拟录取／正式录取／已就业／待定，反映目前结果 |
| 统计状态 | 初始占位／填报中／已核实，反映统计工作进度 |
| 来源 | 可留空；非占位且人数大于0时必填，如匿名填报汇总依据 |
| 更新时间 | 必填，有效日期 |

同一届、路径、关系、机构类型、接收单位、院系、方向和结果状态完全相同的记录应合并人数，不重复建行。汇总不得超过已填报人数或年级总人数。原始调查需由维护者先去重，公开匿名汇总无法识别同一人的重复填报。

“结果状态”与“统计状态”不是同一件事：某人的结果可以是“意向”，但该项统计已经核实。网站接收单位列表同时展示两种状态，避免把意向当作正式录取。

## 保持可维护

模板的编辑辅助覆盖前1000条；新增很多记录时扩大下拉和公式范围。网站导入本身没有1000行限制。未知字段会被拒绝，应按[开发说明](开发与交接.md)增加功能。不要自行新增具名同学、手机号等列后尝试公开。
