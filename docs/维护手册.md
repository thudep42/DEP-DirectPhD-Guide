# 维护手册

## 一次性准备腾讯文档

1. 用资料库所有者账号进入[腾讯文档](https://docs.qq.com/)，导入独立交付的`工物推研资料库.xlsx`，建立普通在线表格。
2. 检查六张表的名称、第一行列名、日期和空白单元格是否保留：使用说明与配置、方向字典、导师资料、年度招生、去向汇总、资料索引。
3. 把编辑权限授予少数维护者，按年级需求单独设置查看权限。网站公开访问权限与表格权限互相独立。
4. 将希望展示的共享链接填入“使用说明与配置”的“腾讯文档链接”。留空时网站展示“共享表格待接入”。不要填仅自己能看的链接，也不要填包含个人凭据的链接。
5. 用另一个允许访问的账号或无痕窗口检查查看权限，并在手机上检查一次。

工作簿中的公式、筛选和下拉选项是辅助工具。不同在线编辑器可能改变样式或校验；第一次导入后，应立即导出一份Excel并执行下面的校验，确认往返兼容。网站数字由基础数据重算，不读取表格右侧的汇总公式。

## 每次更新网站

```mermaid
flowchart LR
  A[维护腾讯文档] --> B[电脑导出整本Excel]
  B --> C[本地导入并校验]
  C --> D[预览检查]
  D --> E[提交公开快照]
  E --> F[手动发布]
```

1. 在腾讯文档修改人数、来源、更新时间和统计状态。完成后从电脑端导出**整个工作簿**为`.xlsx`，保留六张表，不能仅导出当前工作表。
2. 将这份Excel放入网站项目的`local-imports/`目录。这个目录一次只保留一份待导入的`.xlsx`，否则工具会请你明确选择。
3. 双击项目中的`更新网站数据.cmd`。首次使用先按README安装依赖。也可以在项目终端指定文件：

   ```powershell
   pnpm import:data "D:\资料\腾讯文档导出.xlsx"
   ```

4. 校验失败时，原发布数据保持不变；根据提示的工作表、行号和列名修正Excel，再导入。成功时保存新的`public/data/site-data.json`，并在`local-snapshots/`备份旧快照。
5. 运行`pnpm test`、`pnpm build`、`pnpm preview --port 4173`，检查年度、总数、状态、来源和腾讯文档入口。导入成功并不代表已经发布。
6. 仅提交准备公开的源码和快照。按[首次发布说明](首次发布.md)手动触发Actions。腾讯文档编辑和普通GitHub提交均不会自动发布。
7. 部署成功后，用手机重新打开网站，核对页脚的快照时间及本次修改。

## 录入2023级真实去向

- 当前大三是2024级，对应2027年推免、2028年博士入学；这里统计的是上一届2023级去向。2023是本科入学年级，2027是推免年，2028是本次招生的博士入学年，三个口径分开填写。
- 先在“去向汇总”定位对应行。录入非零人数时，将该行“统计状态”改为“填报中”，填写来源和更新时间。配置表“去向统计状态”也要与默认年级整体状态一致。
- 如果仍有未调查的占位行，整体状态保持“初始占位”，除非已存在“填报中”行；工具会提示应该填写的整体状态。
- 实际确认无人时，将人数填0、状态改为“已核实”。“已核实的0”和“初始占位的0”含义不同。
- 未知接收单位、年级总人数或已填报人数留空，不要编造；人数记录本身必须为非负整数。
- 每位同学只计入一条当前去向。意向后来变为拟录取或正式录取时，更新原统计或在旧组合中扣减，再在新组合中计入，防止重复。
- “直博、硕士、就业、其他、待定”是路径；“工物系、清华其他单位、校外”表示关系；“高校、科研院所、企业、其他”表示机构类型。研究院既可能属于清华，也可能在校外，两项分别填写。
- 本系直博必须选一个本系方向编号。外系、外校或科研院所的研究方向写在“研究方向”，本系方向编号留空。
- 不在模板中的接收单位可以新增一行。复制相近行，使用新的唯一记录编号，再修改分类、人数和来源。
- 完成核实后，将这届全部记录改为“已核实”，同步配置状态。只有年级总人数、已填报人数和去向人数合计完全一致、且全部行已核实时，网站才显示人数比例。

例如：假设以后收到**2人本系加速器直博**的填报，这是操作示例，不是实际数据。找到加速器占位行，将人数改2、统计状态改“填报中”、来源写实际填报依据，更新日期，再把配置状态改“填报中”。没有得到全班人数时，覆盖人数继续留空。

覆盖人数配置只对应当前默认年级。切换默认年级时，同时更换总人数、已填报人数和状态；其他年级仍可查看人数，但第一版不计算其覆盖比例。

## 增加下一年度招生

1. 复制“年度招生”中上一年度的行，粘贴到表末。
2. 修改“博士入学年度”，填写推免次年的入学年：例如2028年推免应填2029。核对每位导师的“该年度博导列入”和来源。这个字段保存该年度名单判断，不从最新师资标记自动倒推。
3. 重置“确认计划”和“实际人数”为空。不能把上一年的计划当成新一年的计划。
4. 默认每位当年度博导假设1人。未列入博导名单的导师假设人数必须0；有确认信息后单独录入确认计划，并记录适用口径、来源、更新时间。
5. 一个年度＋一位导师只能一行。新增导师先在“导师资料”登记唯一编号。
6. 更改配置表的默认博士入学年度。网站年度选择器自动显示前一年的“推免年度”，同时注明博士入学年份。配置表右侧也显示对应推免年。

初始2027年推免（2028年博士入学）的师资依据是2026年10月3日官网名单，属于假设，不代表官网已发布对应招生计划。

## 修改方向、资料与表格结构

- 只改方向显示名称时修改“方向名称”，保持“方向编号”不变，相关记录会继续关联。
- 新方向先加入“方向字典”，使用新的唯一编号，再给导师和资料选用。模板方向下拉范围目前是第2至10行；增加方向时，应手工扩大下拉引用范围。配置右侧公式最多引用1000行，超出时也要扩大。
- 不要为方便清理而删除被历史年度使用的导师、方向，或停用有招生历史的方向。导师归属方向变更会影响历史分组，遇到此情况先按开发文档扩展“年度方向归属”，再调整数据。
- 新资料填写标题、类别、链接和来源；相关方向可留空。停用资料将“是否启用”改为“否”。
- 不能随意改表名或第一行列名；列顺序可以调整。增加新列属于功能扩展，需要同步字段、校验与页面。额外列不会被悄悄公开。
- 私人联系方式、具名去向、填报凭据等保存在另一个受限原始表；本模板用于官网信息和匿名汇总。

## 恢复与交接

导入后发现问题，优先修正表格重新导入。也可从`local-snapshots/`复制上一个有效快照覆盖`public/data/site-data.json`，运行校验与预览，再提交并重新手动发布。已经公开的数据以GitHub提交记录为准，可恢复此前有效版本。

交接时转交GitHub仓库管理权限、腾讯文档所有权或编辑权限、维护说明和最近一次发布记录。无需传递个人密码或令牌。
