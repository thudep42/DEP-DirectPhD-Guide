## 第一版的数据口径

- 师资按2026年10月3日官网快照核对：83条人员资料，56位列入博导汇总页。
- 当前大三是**2024级**，默认展示**2027年推免（2028年博士入学）**。表格和数据记录保存博士入学年2028，网页自动按前一年展示推免年。每位博导假设招1人，共56人；这不是学校确认的招生计划。确认计划和实际人数均未知，留空。
- 九个方向的估算分别是：加速器物理及应用10、辐射物理与探测7、粒子信息获取与处理9、核电子学与控制6、辐射防护与环境保护4、技术物理5、核能科学与工程管理8、医学物理与工程2、近代物理5。
- 程建平个人页注明博导，但未列入博导汇总页，单列在“名单差异与统计口径”，不进入默认56人的估算。
- 2023级指**本科2023年入学**。各方向及其他路径初始均为0，并标为“初始占位”。0不代表已调查确认无人；年级总人数和已填报人数留空，不显示比例。
- 官网师资信息见[教师队伍](https://www.ep.tsinghua.edu.cn/szdw/jsdw.htm)、[博士生导师汇总](https://www.ep.tsinghua.edu.cn/szdw/bssds1.htm)。个人职务与博导身份分开保存。

## 本地运行

安装Node.js 24 LTS和pnpm 11.25.0，在本目录打开终端：

```powershell
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地网址。生产预览：

```powershell
pnpm test
pnpm build
pnpm preview --port 4173
```

如果Node安装环境不提供Corepack，可安装指定版本pnpm：`npm install -g pnpm@11.25.0`。本项目不需要服务器、数据库、腾讯文档密码或GitHub令牌。

## 程序目录

```text
DEP-DirectPhD-Guide/
├─ src/                     页面、组件、数据读取与类型
├─ shared/                  表格字段、数据校验、业务统计
├─ scripts/                 表格导入与Windows更新入口
├─ public/data/             唯一发布数据快照
├─ tests/                   业务测试与固定初始样本
├─ docs/                    中文维护、发布和开发说明
├─ local-imports/           本地导出文件，禁止提交
├─ local-snapshots/         本地备份，禁止提交
└─ .github/workflows/       手动GitHub Pages发布
```

网站程序全部放在这个目录。源码包只有一层同名目录；工作簿独立交付。上传GitHub时使用**本目录内的内容**作为仓库根目录，保留隐藏的`.github`目录。不要把上级科研文件夹上传。
